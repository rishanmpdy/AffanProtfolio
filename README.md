# Affan Portfolio

A personal portfolio site built with React, Vite, Tailwind CSS, Redux Toolkit, and React Query.

## Getting Started

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`

## Available Scripts

- `npm run dev` starts the Vite development server
- `npm run build` creates a production build
- `npm run preview` previews the production build locally

## Project Stack

- React
- Vite
- Tailwind CSS
- Redux Toolkit
- React Query
